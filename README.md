# 🧩 Mini Project

A React application created as a hands-on project for learning and experimenting with frontend development.

## 🧰 Tech Stack
- React
- JavaScript
- HTML and CSS

## 🚀 Getting Started
Make sure Node.js and npm are installed.

```bash
git clone https://github.com/jugal4096/mini_project.git
cd mini_project
npm install
npm start
```

The development server typically opens at [http://localhost:3000](http://localhost:3000).

## 📦 Production Build
```bash
npm run build
```
